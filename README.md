# Task 6: Host a Static Website with GitHub Pages

## Project Overview

This project demonstrates how to create and host a static website using GitHub Pages.

## Technologies Used

* HTML
* CSS
* Git
* GitHub
* GitHub Pages

## Features

* Responsive portfolio website
* About Me section
* Technical Skills section
* Projects section
* Contact section
